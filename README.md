# AI-Bro
Un asistente de IA en TUI. Tiene integración con: OpenAI, Google, Antrophic, DeepSeek, Mistral y Ollama. Funcionan mediante API Key, menos Ollama que se ejecuta localmente.

Instala las dependencias de requirements.txt con pip para una instalación base.
Las dependencias de opt-requirements.txt son opcionales, por si quieres más proveedores de IA.
Instala las dependencias de full-requirements.txt con pip para una instalación completa.
